# My Money — ເວັບບັນທຶກລາຍຮັບ-ລາຍຈ່າຍ

## ໄຟລ໌ໃນໂປຣເຈັກ
- `index.html` — ໂຄງສ້າງໜ້າເວັບ
- `style.css` — ຮູບແບບ ແລະການຮອງຮັບມືຖື
- `app.js` — ການບັນທຶກ, ຄຳນວນ, ລາຍງານ ແລະແກ້ໄຂລາຍການ

## ວິທີເປີດໃຊ້
1. ແຕກໄຟລ໌ ZIP.
2. ເປີດໂຟນເດີ `my-money`.
3. ກົດເປີດ `index.html` ດ້ວຍ Chrome, Safari ຫຼື Edge.
4. ເລືອກລາຍຈ່າຍ/ລາຍຮັບ, ເລືອກໝວດໝູ່ ແລ້ວກົດປຸ່ມຈຳນວນເງິນ.

## ຟີເຈີ
- ປຸ່ມດ່ວນ 10,000 / 27,000 / 49,000 / 89,000 ກີບ
- ກອກຈຳນວນເງິນເອງ (ກຳນົດເອງ) ພ້ອມໃສ່ຈຸດຄັ່ນຕາມຫຼັກພັນອັດຕະໂນມັດ; ກົດ Enter ຫຼື “ເພີ່ມ” ເພື່ອບັນທຶກ
- ຄຳນວນລາຍຮັບ, ລາຍຈ່າຍ ແລະຍອດສຸດທິ
- ລາຍງານມື້ນີ້, ອາທິດນີ້ (ຈັນ-ອາທິດ), ເດືອນນີ້
- ແຍກລາຍຈ່າຍຕາມໝວດໝູ່
- ແກ້ໄຂ ແລະລຶບລາຍການ
- ສຳຮອງຂໍ້ມູນອອກເປັນ JSON
- ຂໍ້ມູນເກັບຢູ່ໃນ `localStorage` ຂອງ Browser

## ສຳຄັນ
- ຂໍ້ມູນຈະຢູ່ໃນ Browser ແລະອຸປະກອນທີ່ໃຊ້. ບໍ່ຊິງຄ໌ອັດຕະໂນມັດລະຫວ່າງມືຖື ແລະຄອມພິວເຕີ.
- ການລຶບຂໍ້ມູນ Browser ຫຼືໃຊ້ Private/Incognito mode ອາດເຮັດໃຫ້ຂໍ້ມູນຫາຍ. ຄວນກົດ “ສຳຮອງ” ເປັນປະຈຳ.
- ສາມາດກົດ “ນຳເຂົ້າ” ເພື່ອເລືອກໄຟລ໌ JSON ທີ່ສຳຮອງໄວ້; ການນຳເຂົ້າຈະແທນຂໍ້ມູນປັດຈຸບັນ.
- ຟອນ Lao ຈະໃຊ້ Google Fonts ເມື່ອມີ Internet; ຖ້າບໍ່ມີຈະກັບໄປໃຊ້ຟອນທີ່ມີໃນອຸປະກອນ.
